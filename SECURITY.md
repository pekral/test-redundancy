# Security policy

`pekral/test-redundancy` is a development tool. It runs your test suite and reads the coverage it writes; it makes no
network calls.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/pekral/test-redundancy/security/advisories/new)
or e-mail kral.petr.88@gmail.com. You get an answer within a week.

## Supported versions

Only the latest release receives fixes.
